# Lyrics 1.0.2

本版本汇总自 1.0.1 以来的功能更新与问题修复。

## 新功能与改进

- 可直接把编辑后的歌词覆盖写入当前音频的内嵌歌词；写入后会重新读取核对，保留音频内容及其他标签。
- 安装目录与开始菜单提供卸载入口。
- 播放栏新增音量调节，并记住上次的音量设置，重启后继续使用。
- 播放时草稿栏跟随当前高亮句；手动滚动后暂停自动跟随，点击“回到高亮句”可将其尽量滚动到居中位置并恢复跟随。
- 问题行采用更醒目的高亮显示，行号也会提示标记状态；标记时不再向备注栏写入提示，避免界面尺寸跳动。
- 双击编辑时间时，编辑框随对应歌词行同步滚动；编辑行离开可视区域时提交编辑，避免输入框停留在错误位置。

## 修复

- 曲目信息行的前奏空间不足时，导出 LRC 仍会显示警告并继续；所有曲目信息时间戳设为 `[00:00.000]`，歌词自身时间不变。
- 如果有效的 Auto-LRC 模型已位于程序内的 `auto-lrc-engine/upstream/`，应用会校验后直接使用，避免误报模型未安装，也不会复制或移动模型。

## 其他

- Windows 安装程序和源码 ZIP 由此版本的发布流程重新构建，并附带 SHA-256 校验文件。
- 原始 Auto-LRC 模型不包含在安装包或源码 ZIP 中；缺少模型时，仍需运行模型下载入口。
